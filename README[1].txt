# Cinematic Diwali Website

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or your phone browser.
3. Tap **Tap to light up your Diwali**.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository, for example `diwali-celebration`.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. After GitHub publishes it, copy the Pages URL and share that link in your WhatsApp Status.

The page is mobile-friendly and uses no external libraries or image downloads. After the visitor taps the celebration button, each firework burst plays a short synthesized boom-and-crackle sound. Audio starts only after that tap because browsers require user interaction before playing sound.
